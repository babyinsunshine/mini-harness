# Minimal coding harness：已确定设计

架构更新：本文记录初版设计。核心循环现已按 [LangGraph 迁移设计](2026-10-18-langgraph-design.md)
改为显式节点，原 Middleware 由普通服务替代；其余机制沿用。

用户已要求开始开发。项目临时命名 mini-harness；新的独立目录，不改动现有项目。

## 原则

- Python >=3.11；复用 LangChain create_agent / LangGraph，不重写模型与工具循环。
- 优先可读性和机制精简；函数和具体类型即可，不自建插件框架。
- 初版为本地 CLI。尚未讨论的子 agent、MCP、skills、长期记忆，开发前继续讨论，不添加空壳。
- 所有会执行本地命令的验证使用临时目录；真实模型通过外部配置连接，不读取或打印凭据。

## 本次交付

1. 四个基础工具 bash / read_file / write_file / edit_file；搜索通过 bash 中的 rg。
2. Bash：每次新进程；前台命令完成后延续真实 cwd；继承启动环境，每次命令前 source 会话 env.sh；临时 export 不跨命令。调用串行；后台任务不回写 cwd。
3. 前台等待超时转后台；显式后台启动；日志文件；task_id；stdin 追加和 EOF；停止整个进程组；CLI 退出时清理。无 PTY。
4. SQLite checkpointer 保存 agent 状态；同一个 session_id 对应 thread_id。JSONL 保存消息和压缩记录；大输出保存 artifacts。原文记录与当前模型上下文分开。
5. 压缩基于用户指定文章：https://deepseek.csdn.net/6a2233c610ee7a33f277cf93.html 。大输出落盘→条件 Micro→Auto→Blocking→明确超限错误的 Reactive 兜底。摘要九项、手动 /compact、自定义要求、部分压缩、失败熔断、恢复与清理。
6. 会话笔记可选；模型生成笔记，由代码保存；摘要与覆盖位置一起保存，复用后保留未覆盖消息；失败回退即时摘要。后台更新不得覆盖更新的压缩状态。
7. CLI：多轮、文本流、单次 -p、恢复、会话列表、任务列表、手动压缩、Ctrl-C 取消当前执行、正常退出清理。
8. 工具权限：采用 2026-10-18-permissions-design.md 中的 allow/ask/deny 策略，在执行记录之前审批；项目和当前会话内普通文件读写直接允许，目录外询问，危险操作拒绝。单次确认复用现有 CLI 输入线程，不提供 OS 沙箱。

## 实现约定

- 使用 asyncio 子进程和直接写文件的 stdout/stderr，避免输出无限积压内存。stdin=PIPE。
- ContextMiddleware.before_model 更新有效消息；wrap_model_call 记录主模型请求开始时间，并识别明确上下文超限、有限恢复，恢复结果必须写回 checkpoint。
- Reactive 与 Auto 分工独立：明确超限后不调用摘要模型，按完整消息组从旧到新裁剪，以估算请求量减半为目标。保留最新真实用户请求、已有摘要、最新运行上下文、最新 assistant 轮次及其后的消息；新用户消息使用 user- 前缀 ID，旧会话按内部消息前缀兼容识别，避免把后台通知当作用户请求。
- Reactive 只有存在净缩减且低于本地阻塞阈值时才重试主请求一次。成功后通过模型响应的状态更新写回 checkpoint、失效笔记并记录裁剪边界；失败不提交裁剪候选。模型收到省略提示及原 transcript 路径，原文不从磁盘删除。仅剩保护内容时明确失败；Blocking 保持请求前拒绝，不增加额外摘要层。
- 消息保留以完整模型/工具轮次为单位；不切断工具调用与结果。日志中记录的工具输出过大时引用 artifacts。
- 自动阈值按模型窗口、输出预留、安全余量计算；可覆盖窗口与预算；默认按 128K 窗口保守配置，未知模型启动时说明并允许显式设置。
- Micro 采用 OpenCode 式预算裁剪：倒序扫描，至少保护最近两组完整工具往返，同时保护约 40000 tokens 的近期工具输出（不额外累加，并行组完整保留）。候选净节省合计超过 20000 tokens 后才批量替换为文件引用，不再按全上下文压力或末尾消息条数触发。
- 主 agent 模型请求间隔达到 300 秒时，近期保护不变，候选净节省为正即可裁剪。请求开始时间持久化到会话元数据，摘要和笔记不刷新，也不注入提示词；这是本地策略，不保证远端缓存已过期。四项 Micro 参数可经 CLI 配置并随会话恢复。
- 单次大输出限制属于工具返回阶段，完整输出落盘，Bash 直接写日志。Micro 不调用模型、不重复裁剪已有引用、不用更长指针替换短结果；未达到批量门槛不落盘。不模拟 Anthropic 内部 cache_edits，原输出仍可从历史或 artifacts 查找。
- 摘要保留需求、概念、文件、错误、问题处理、用户消息、待办、当前工作、下一步；不要求输出内部推理。
- 普通工具包装器只登记开始、调用一次 handler、保存结果，不重复查询历史调用。
  恢复入口按 tool_call_id 补齐已落盘的结果；异常或中断统一记为 error。
  结果未确认时交给模型检查文件和日志，不自动重跑。
- 同一会话用文件锁限制一个写入者；进程记录保留，重启后活动任务标记 interrupted，不信任旧 PID。
- 保留前后台完成事件。当前模型执行中只排队，在后续安全的模型调用点注入；空闲 CLI 可消费事件。
- 完整 TUI 自动化、操作系统级沙箱、跨进程常驻 daemon 不在本次已商定范围。

## 文件职责

独立审查后的修正：`state.sqlite` 专用于异步 LangGraph checkpoint；运行元数据、笔记和
工具执行记录保存到 `runtime.sqlite`。同一会话锁覆盖两个文件。这样避免同步写入阻塞
事件循环，导致异步 checkpoint 无法提交；增加一个数据文件，省去全量异步化的复杂度。
摘要只发送一次请求；输入超预算或模型调用失败时保留原上下文，不拆批重试或静默丢弃输入。
shell 退出后也必须清理其遗留子进程；后台服务使用显式后台任务。

每个会话自动创建唯一的 `env.sh`，恢复时保留内容。系统提示在每次模型请求中提供它的
绝对路径，说明智能体可通过文件工具修改，下一次 Bash 调用前会自动 source。
切换工作目录继续使用同一个文件，智能体直接读写这一份会话环境脚本。

系统提示在组装 create_agent 时固定，包含核心规则、项目根目录、env.sh 绝对路径。
当前 cwd 和根 AGENTS.md 以运行上下文消息提供，首次或内容变化时只追加到历史末尾，
不修改旧消息或系统提示，保留普通调用之间的缓存前缀。压缩后恢复最新运行上下文，
该消息与普通历史一起计入上下文预算。

- session.py：SQLite 元数据、JSONL 记录、artifacts、会话锁。
- processes.py：进程生命周期、cwd、日志、stdin、完成队列。
- tools.py：四个基础工具及进程控制的薄封装。
- context.py：Middleware 调度、运行时上下文、后台笔记和压缩状态。
- compact.py：预算、各层压缩算法、摘要后恢复；prompts.py：摘要和笔记提示词。
- agent.py：create_agent 组装与会话生命周期。
- cli.py：参数、输入、流显示、命令和中断。

## 验证

使用真实临时文件、真实 Bash 子进程及离线脚本模型验证完整 graph。
重点覆盖 export/cwd、后台 stdin/EOF、取消后子进程清理、跨实例恢复、原始日志不丢失、工具配对、压缩取消与超限重试、笔记覆盖边界、未知工具结果不重复执行。
真实供应商模型调用需要用户自己的模型配置和凭据；离线测试不能替代真实 API 冒烟验证。
